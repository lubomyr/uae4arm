How to build uae4arm
====================

uae4arm is built inside pelya's libSDL environment for Android (androidsdl),
with a patch to it kept in this repository. These steps are the ones used for
the releases, on 64-bit Ubuntu 24.04.


1. Packages

sudo apt-get install git openjdk-17-jdk unzip python3 lhasa

For the Amiga tools in amiga/ also: binutils-m68k-linux-gnu


2. Android SDK and NDK

Install Android Studio, or only the command line tools, and with the SDK
Manager (or sdkmanager) get:

sdkmanager "platforms;android-37.0" "build-tools;36.0.0" "ndk;25.2.9519653" "platform-tools"

Other NDK versions are not tried. The build signs its test package with the
debug key; Android Studio makes ~/.android/debug.keystore, or make it with:

keytool -genkeypair -keystore ~/.android/debug.keystore -alias androiddebugkey \
    -storepass android -keypass android -keyalg RSA -validity 10000 \
    -dname "CN=Android Debug,O=Android,C=US"


3. Environment

export ANDROID_SDK_ROOT=~/Android/Sdk
export ANDROID_NDK_HOME=$ANDROID_SDK_ROOT/ndk/25.2.9519653
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
export PATH=$ANDROID_SDK_ROOT/build-tools/36.0.0:$JAVA_HOME/bin:$PATH


4. androidsdl, at the commit the patch is made for

cd ~
git clone https://github.com/pelya/commandergenius androidsdl
cd androidsdl
git checkout e0d402e50

Its submodules are other applications; uae4arm does not need them.


5. uae4arm

cd ~/androidsdl/project/jni/application
git clone https://github.com/lubomyr/uae4arm


6. capsimage, the IPF disk image library

androidsdl does not have it. It is FS-UAE's capsimg, with the Android.mk and
the configured config.h kept in capsimage/ of this repository:

cd ~/androidsdl/project/jni
git clone https://github.com/FrodeSolheim/capsimg capsimage
cd capsimage
git checkout ed4cb09
rm CAPSImg/dllmain.cpp
cp ../application/uae4arm/capsimage/Android.mk .
cp ../application/uae4arm/capsimage/config.h CAPSImg/


7. QuarkTex NG's host library, and gl4es for it

uaenative.library (Misc in the menu) lets QuarkTex NG's Amiga libraries draw
3D with the GPU. Its host library is QuarkTex NG 1.0 beta 3 (Aminet
driver/video/QuarkTexNG.lha) with the changes for Linux and Android in
quarktexng/ of this repository. On Android it is two libraries: one for
ogles2.library on OpenGL ES 3, and one for minigl.library and agl.library on
gl4es. Get QuarkTexNG.lha from https://aminet.net/package/driver/video/QuarkTexNG
into ~/androidsdl/project/jni, then:

cd ~/androidsdl/project/jni
lha x QuarkTexNG.lha
mkdir quarktexng
mv QuarkTexNG/Source quarktexng/src
cd quarktexng
cp ../application/uae4arm/quarktexng/Android.mk .
patch -p1 -d src < ../application/uae4arm/quarktexng/quarktexng.patch
git clone https://github.com/ptitseb/gl4es
cd gl4es
git checkout bc4314d8

The patch is for 1.0 beta 3: if Aminet has a newer QuarkTex NG by then, its
Source folder may not take it.


8. The patch to androidsdl

It adds what uae4arm needs of the Android wrapper: the on-screen controls'
options, MIDI, the video and browser windows and more.

cd ~/androidsdl
git apply project/jni/application/uae4arm/androidsdl.patch


9. Build

cd ~/androidsdl
./build.sh release uae4arm

project/app/build/outputs/apk/release/app-release.apk is signed with the debug
key, to try out; app-release-unsigned.apk is the one to sign for a release.
With KEEPSYMBOLS=1 before ./build.sh, project/obj/local/<abi>/libapplication.so
keep their symbols, which crash reports need.


Notes

- The build does not follow header files: after changing one, remove
  src-arm64-v8a and src-armeabi-v7a here, so that everything is built again.
- Changes to the wrapper (project/java, project/jni/sdl-1.2 and so on in
  androidsdl) belong in androidsdl.patch. Make it again from the androidsdl
  directory with
      git diff > project/jni/application/uae4arm/androidsdl.patch
  after "git add -N" for new files, so that they are in it.
- ./LinuxBuild.sh builds uae4arm for a Linux PC, with the guichan of the
  patched androidsdl (steps 4 to 8): no Android wrapper and no JIT, but the
  quickest way to try emulation changes. The script tells the packages it needs.
  QuarkTex NG's host library for it (libegl-dev, libgl-dev and libglu1-mesa-dev
  needed), into build-linux/run/plugins:
      cd ~/androidsdl/project/jni/quarktexng/src
      g++ -shared -fPIC -O2 -std=c++11 -Igl -o quarktexng-linux-x86-64.so \
          host/quarktex.cpp host/gldecode.cpp host/w3d.cpp host/mgl.cpp \
          host/ogles2.cpp host/ffp.cpp host/gl3.cpp host/present.cpp \
          -lEGL -lGL -lGLU
- Changes to QuarkTex NG's host belong in quarktexng/quarktexng.patch: a git
  diff of its Source folder against the Aminet release.
- amiga/build.sh builds the Amiga tools (AndroidPlay, AndroidBrowser) into
  amigaApps/.
